# @crystal-design/focus-effect

Jelly spring effect that swells the active item of any group and nudges its neighbours aside, for React.

```bash
npm install @crystal-design/focus-effect
```

[Live demo and code](https://crystal-design.vercel.app/#/focus-effect) · [All components](https://github.com/joezhuo2/crystal-design#readme)

Part of [Crystal Design](https://github.com/joezhuo2/crystal-design). Needs React 18 or later. MIT licensed.
